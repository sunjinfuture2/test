# AI 데이터센터 내부 둘러보기 (AIDC / Immersive Explore)

충주 AI 데이터센터 도면을 실측 미터 스케일로 세우고, 1인칭으로 걸어
다니며 장비를 살펴보는 웹 시뮬레이션입니다. 부감 다이어그램
(`../aidc-3d-dashboard`)과 **도면 빌더·용어 데이터를 같은 파일로 공유**하고,
실내 마감(재질·조명·가구·승강기)과 탐색 UI는 이쪽에서 따로 입힙니다.

대시보드 헤더의 **복층 / 단층 / 내부 둘러보기** 드롭다운에서 들어옵니다
(`/3d/` → `/walk/`). 화면 오른쪽 위 **돌아가기**로 용어사전으로 나갑니다.

## 조작

| 키 · 조작 | 동작 |
| --- | --- |
| `W` `A` `S` `D` / 화살표 | 이동 |
| 마우스 | 시선 (화면을 클릭하면 포인터 락, 드래그로도 됨) |
| `E` | 조준한 장비 설명 · 승강기 칸 안에서는 층 이동 |
| `Space` | 장비 설명 열기 / 닫기 |
| `Esc` | 열린 창 닫기 (설명·설정) · 포인터 락 해제 |
| `1` … `5` | 이동 속도 5 / 7.5 / 10 / 12.5 / 15 m/s |
| `M` `F` `H` `T` | 평면도 · 냉각 흐름 · 시네마(UI 숨김) · 가이드 투어 |

층 이동은 **1층 동쪽 끝(도면 100, 31.8)의 승강기**로 합니다. 벽을 통과하지
않고 실제로 뚫린 문과 승강기로만 다니게 되어 있습니다. 평면도 패널의 층 탭과
QUICK VIEWS는 각 층의 대표 지점으로 바로 건너뜁니다.

## 구조

```
index.html        화면 마크업 (탐색 UI 전체)
src/explore.css   화면 스타일
src/main.js       탐색 코드 — 실내 마감 · 이동 · 조준 · 투어 · 승강기 · 평면도
src/scene/        도면 지오메트리 — 대시보드와 같은 빌더, 스케일만 1(실측 m)
src/walk/
  access.js       벽에 문 뚫기 · 통로를 막은 장비 치우기
  collect.js      층 높이 · 충돌 상자 · 장비 목록 수집
  Collision.js    2 m 공간 해시 위의 수평 AABB
src/data/         장비 설명 데이터 (대시보드와 공유)
```

`src/main.js`는 위 모듈을 `AIDC_ENGINE` 객체 하나로 받아 씁니다. 도면을
만드는 쪽과 탐색하는 쪽을 이 경계로 갈라 두면, 도면이 바뀌어도 탐색 코드는
손댈 데가 없습니다.

`buildFacility.js`는 손대지 않습니다 — 용어사전과 같은 파일이라 거기서 벽을
자르면 부감 다이어그램의 벽에도 구멍이 뚫립니다.

### 문 (access.js)

도면 모델의 벽은 한 장짜리 통 슬래브입니다 — 전산동 남측 벽 하나가 105 m를
끊김 없이 가로지릅니다. 위에서 내려다보는 다이어그램에서는 맞지만, 안에서
걸으면 드나들 데가 한 곳도 없습니다.

벽을 통과하게 만드는 것(충돌체만 지우기)은 답이 아닙니다 — 눈앞의 벽을 뚫고
지나가면 그 순간 건물이 아니라 화면이 됩니다. 그래서 **지오메트리를 실제로
잘라** 개구부를 만들고 위에 인방을 남깁니다. 충돌체는 잘린 지오메트리에서
다시 뽑히므로 저절로 따라옵니다.

- 지정 개구부: 연결통로 양 끝(통로 유효폭 그대로 5.3 m), 항온항습실 갤러리
  벽 아홉 곳(팬월 사이 틈 2.7 m에 맞춤 — 틈과 어긋나게 뚫으면 문을 지나자마자
  팬월 옆구리에 막힙니다)
- 그 밖의 내벽: 22 m마다 4.5 m 폭 · 4 m 높이로 자동 배치. **외벽은 자르지
  않습니다** — 건물 껍데기에 구멍을 내면 복도가 바깥 허공으로 뚫립니다.
- 통로를 막은 장비: 보행 높이에서 걸리고 **통로 유효폭의 절반 넘게** 가리는
  그룹만 통로 밖으로 물립니다. 머리 위 6 m로 지나가는 배관이나 0.8 m짜리
  기둥은 두고, 2층 다리를 4.4 m 막던 소화가스 실린더 뱅크만 옮겨집니다.

로비 유리벽 개구부(`openWall`)는 탐색 코드가 같은 방식으로 한 곳 더 냅니다.

### 충돌·조준·평면도가 공유하는 것

세 기능 모두 `collectColliders`가 만든 **메시 단위** 수평 AABB 목록 하나를
씁니다. 용어 그룹 단위로 묶으면 안 됩니다 — GPU 랙처럼 홀 전체에 9열로
퍼진 그룹은 바운딩 박스가 홀을 통째로 채워 걸어 들어갈 자리가 없어집니다.

- **충돌**: 축을 나눠 밀어 벽에 닿으면 멈추지 않고 미끄러집니다. 최고 속도
  15 m/s에서는 한 프레임 변위가 얇은 벽보다 두꺼우므로 0.08 m 이하로 쪼개
  밉니다 — 안 쪼개면 벽을 지나칩니다.
- **조준**: 화면 중앙에서 레이 한 발, 사거리 5.5 m. 벽·바닥이 먼저 맞으면
  조준 없음이라 벽 너머는 잡히지 않습니다.
- **투어·길찾기**: 가이드 투어는 같은 충돌 지도 위에서 A*로 경로를 찾습니다.
  `window.AIDC.validateTour()`가 13개 구간이 모두 실제로 걸어 닿는지
  확인해 줍니다(층이 다른 구간은 승강기).

npm install
npm run dev                                         # 로컬 개발 서버
