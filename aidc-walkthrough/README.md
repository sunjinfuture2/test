# AI 데이터센터 내부 둘러보기 (1인칭 워크스루)

충주 AI 데이터센터 도면을 실측 미터 스케일로 세우고, 1인칭으로 걸어
다니며 장비를 살펴보는 웹 시뮬레이션입니다. 같은 저장소의 부감
다이어그램(`../aidc-3d-dashboard`)과 도면 빌더·용어 데이터를 공유하되,
실내에서 보이도록 재질·조명·충돌을 새로 구성했습니다.

대시보드 헤더의 **복층 / 단층 / 내부 둘러보기** 드롭다운에서 들어옵니다
(`/3d/` → `/walk/`).

## 조작

| 키 | 동작 |
| --- | --- |
| `W` `A` `S` `D` / 화살표 | 이동 |
| 마우스 | 시선 |
| `Shift` | 달리기 (2.1배) |
| `Space` | 조준한 장비 설명 열기 / 닫기 |
| `Esc` | 열려 있는 창 하나 닫기 (설명창 → 시작 카드) |
| `1` … `5` | 이동 속도 (0.9 / 1.4 / 2.6 / 5 / 12 m/s) |
| `[` `]` | 마우스 감도 (기본값의 23 % ~ 409 %) |
| `PgUp` `PgDn` | 층 이동 (B1 · 1F · 2F · 옥상) |

`Esc`는 브라우저가 포인터 락을 함께 풀어 버리므로, 설명창을 닫고 계속
걸으려면 `Space`가 낫습니다. 락이 풀리면 큰 오버레이 대신 아래쪽에 알약
하나만 뜨고, 화면을 누르면 시선 조작이 돌아옵니다.

## 구조

```
src/scene/      도면 지오메트리 — 대시보드와 같은 빌더, 스케일만 1(실측 m)
src/walk/       1인칭 전용
  buildWorld.js   부감 씬을 실내로 개조 · 조명 · 충돌체 · 조준 대상 수집
  Controller.js   이동 · 시선 · 감도 · 속도 프리셋
  Collision.js    2 m 공간 해시 위의 수평 AABB
  Minimap.js      층 평면 + 내 위치
  Hud.jsx         상단 바 · 미니맵 · 조준 힌트 · 설명 패널
src/data/       장비 설명 데이터 (대시보드와 공유)
```

### 부감 씬을 실내로 바꾸는 부분

원본은 위에서 내려다보라고 만든 모델이라 그대로 들어가면 종이 모형
속처럼 보입니다. `walk/buildWorld.js`가 아래를 바꿉니다.

- 반투명 구조체 → 불투명, Lambert → Standard (거칠기·금속성)
- 계통 구분용 색(전력=노랑 등)의 채도를 죽입니다. 색을 살리는 것은
  0.6 m 미만의 작은 면(표시등·표지)뿐입니다 — 채도만 보고 살리면
  복도 전체가 겨자색이 됩니다.
- 천장 라인 조명 + 안개 + ACES 톤매핑
- 다이어그램용 윤곽선·고스트 쉘·층 구분 바닥판은 끕니다. 이때
  `hideAlways`를 함께 세웁니다 — 이 메시들도 층 태그가 있어서 층 필터가
  `visible`을 되살리면 실내 바닥이 통째로 연회색 판에 덮입니다.

### 충돌·조준·미니맵이 공유하는 것

세 기능 모두 `collectColliders`가 만든 **메시 단위** 수평 AABB 목록
하나를 씁니다. 용어 그룹 단위로 묶으면 안 됩니다 — GPU 랙처럼 홀 전체에
9열로 퍼진 그룹은 바운딩 박스가 홀을 통째로 채워 걸어 들어갈 자리가
없어집니다.

- **충돌**: 축을 나눠 밀어 벽에 닿으면 멈추지 않고 미끄러집니다. 질주
  속도(Shift와 겹치면 25 m/s)에서는 한 프레임 변위가 1 m를 넘으므로
  0.12 m 이하로 쪼개 밉니다 — 안 쪼개면 얇은 벽을 지나칩니다.
- **조준**: 화면 중앙에서 레이 5발(중앙 + 상하좌우 약 4°). 벽·바닥이
  먼저 맞으면 조준 없음이라 벽 너머는 잡히지 않습니다.
- **미니맵**: 같은 상자를 위에서 본 것이 곧 평면입니다. 평면도 데이터를
  따로 두면 도면이 바뀔 때 한쪽만 갱신되어 어긋납니다. 층 평면은 층이
  바뀔 때 한 번 구워 두고, 매 프레임은 화살표만 다시 그립니다.

```bash
npm install
npm run dev                                        # 로컬 개발 서버
npm run build -- --outDir ../walk --emptyOutDir     # 배포본(/walk) 갱신
```
